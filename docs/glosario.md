# Glosario esencial

| Término | Significado |
| --- | --- |
| APT | Herramienta de alto nivel para paquetes Debian y Ubuntu. |
| Bash | Shell de GNU con variables, funciones, expansión y control de flujo. |
| Boot | Proceso de arranque desde firmware hasta sistema operativo y sesión. |
| Cgroup | Jerarquía del kernel para agrupar procesos y controlar recursos. |
| Daemon | Proceso que opera en segundo plano, normalmente sin interfaz interactiva. |
| Distribución | Kernel más herramientas, paquetes, configuración y ciclo de vida. |
| DNS | Sistema que resuelve nombres de dominio a datos, normalmente direcciones IP. |
| File descriptor | Referencia abierta a un archivo, socket, pipe u otro recurso. |
| Filesystem | Estructura que organiza datos y metadatos sobre un dispositivo o volumen. |
| GID | Identificador numérico de un grupo. |
| GNU | Proyecto que provee muchas utilidades y herramientas de usuario en Linux. |
| Inode | Estructura que guarda metadatos de un archivo, separada de su nombre. |
| Journal | Registro estructurado administrado por systemd-journald. |
| Kernel | Núcleo que administra hardware, memoria, procesos y llamadas al sistema. |
| LTS | Versión con soporte prolongado según la política del proveedor. |
| Mount | Asociación de un filesystem con un directorio de la jerarquía. |
| Netplan | Capa de configuración de red usada por Ubuntu. |
| PID | Identificador numérico de un proceso. |
| Pipe | Canal que conecta la salida de una orden con la entrada de otra. |
| POSIX | Familia de estándares para interfaces y comportamiento de sistemas Unix. |
| Root | Usuario con UID 0 y privilegios administrativos amplios. |
| SELinux | Control de acceso obligatorio usado especialmente en RHEL y Fedora. |
| Signal | Notificación enviada a un proceso para solicitar una acción. |
| Snap | Formato y sistema de paquetes mantenido por Canonical. |
| Socket | Punto de comunicación entre procesos locales o de red. |
| Sudo | Herramienta para ejecutar órdenes con privilegios según una política. |
| Swap | Espacio de almacenamiento usado como memoria virtual auxiliar. |
| Systemd | Suite de init, supervisor de servicios, journal, timers y otras unidades. |
| UID | Identificador numérico de un usuario. |
| Umask | Máscara que restringe permisos al crear archivos y directorios. |
| Unit | Objeto administrado por systemd, como service, mount, timer o swap. |
| UFW | Interfaz sencilla para administrar reglas de firewall en Ubuntu. |
